# Contrato de interfaz
Una pantalla con Monto total, Personas, Propina (%), selector Exacto/Hacia arriba,
botón Calcular y área de pago/error. El modo inicial es Exacto y la propina inicial 0.
Propina borrada o solo espacios significa 0%; no muestra error.
Resultado numérico de dos decimales acompañado por Por persona.
Errores exactos: Monto inválido, Debe haber al menos una persona, Propina inválida.
Ningún error de cálculo conserva el pago anterior. Interfaz desplazable para el teclado.
Sin login, historial, red o persistencia.
